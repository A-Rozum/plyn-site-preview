# Language review

One file per language (`review/<code>.txt`), so a reviewer sees only that version.
Live version of each language: https://plyn.one/<code>/

Codes: `en`, `be` (Belarusian, Cyrillic), `be-latn` (Belarusian, Łacinka), `pl`, `it`, `lt`.

Ask the reviewer to mark: grammar, unnatural phrasing, register (formal or informal address), the headline idiom, and whether the "learning to wave" joke works in that language.
